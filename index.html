VIGENÈRE CIPHER

Encrypt means make a secret message. Decrypt means read it again. Use the same key for both. Spaces, numbers, and symbols stay the same.

HOW TO USE THE CIPHER

Click LOAD EXAMPLE to try it first. Then follow the letters below to see how the key changes the message.

01

ENTER THE TEXT

To encrypt, enter your message. To decrypt, enter the secret message you want to read.

02

CHOOSE A KEY

A key is a word, like LEMON, that tells each letter how far to move. Use letters only.

03

RUN THE CIPHER

Click ENCRYPT to make it secret, or DECRYPT to read it again. To decrypt, use the key that made the secret message.

04

LEARN THE STEPS

Click a letter below, drag the slider, or press Play. Watch the letter move one place at a time.

Want to see the formulas too?
ENCRYPTION C = (P + K) mod 26

Move forward by the key’s number. P = message letter, K = key letter, C = secret letter.

DECRYPTION P = (C - K + 26) mod 26

Move backward by the key’s number. “mod 26” means loop around the 26 letters.

LETTER VALUES A = 0 · B = 1 · ... · Z = 25

A means move 0 places, B means move 1, and Z means move 25. After Z comes A.
